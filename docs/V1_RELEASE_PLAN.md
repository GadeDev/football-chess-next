# Football Chess v1.0 リリース計画

更新日: 2026-07-10

## v1.0 の目的

初めて遊ぶ人が動画で基本を理解し、COM戦またはオンライン戦をスマートフォンで最後まで遊べる状態をv1.0とする。GDDにあるクラブ経営、ジェム、ギャラリー、イベント、掲示板はv1.0に含めない。

## 正式ルール

- 6ゾーン×5レーン、1マス最大3駒
- 前半15ターン、後半15ターン、アディショナルタイムあり
- チーム総コスト16
- 引き分けあり。延長戦・PK戦なし
- PK/FK/CKは自動解決。セットプレー時の手動再配置は行わない
- オフライン入力時間は20秒
- オンラインはサーバー権威で解決する
- 課金による勝率・確率・競技力の強化は行わない

## 対象外

- クラブ経営、施設増築、選手ガチャ、掲示板、広告
- 課金者だけが有利になる駒・確率・ランキング仕様
- v1.0での複数コスト帯マッチング

## 完成判定

次の条件をすべて満たしたときにv1.0候補とする。

1. 初見のテスターが動画を見て、説明なしでCOM戦を完了できる。
2. オンライン対戦を異なる2端末で完了し、切断後も復帰できる。
3. ja/enのユーザー向け文言に翻訳漏れがない。
4. 必須自動テストと対象実機テストがすべて成功する。
5. 匿名統計と監視から、完了率・離脱・エラーを確認できる。
