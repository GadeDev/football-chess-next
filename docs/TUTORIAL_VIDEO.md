# 動画チュートリアル制作ガイド

## 正本

チュートリアルの正本は `football-chess-prototype.html` の `TUTORIAL_SCENES` とL10N字幕である。MP4を直接編集して正本にしない。ルールや翻訳を変更したらシーン定義を更新し、必要な配信用動画を再収録する。

## 収録手順

1. `python3 -m http.server 5174` でローカル配信する。
2. `http://127.0.0.1:5174/football-chess-prototype.html` を開く。
3. ホームの「遊び方」を開く。
4. 設定で収録対象の言語を選ぶ。
5. 対象シーンを選び「最初から」を押す。
6. ブラウザまたはOSの画面収録でチュートリアル枠を収録する。
7. 冒頭と末尾だけをトリミングし、ゲーム内の字幕・速度・演出は加工しない。

## 推奨書き出し

- 横長紹介: 1920×1080 / H.264 / 30fps
- スマートフォン案内: 1080×1920 / H.264 / 30fps
- 音声なしでも理解できる字幕を必須とする
- SNS用は各シーン20〜30秒以内へ編集してよいが、内容は正本と一致させる
